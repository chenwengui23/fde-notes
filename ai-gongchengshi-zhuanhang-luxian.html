后端/运维/数据，三条路转行 AI 落地工程师，各要补什么

原创 · AI 落地实战笔记 · 无夜之境

转行 AI 落地工程师（FDE）的人，大部分已经有技术底子。但不同背景的补课路线完全不同——用错路线，白费三个月。

后端工程师：技术是长板，缺的是「翻译」

你已有：接口开发、系统设计、数据库。这些直接算数，RAG 和 Agent 的服务端就是你在写的东西。要补的是三块：需求诊断（怎么把老板的话变成方案）、提示词工程、验收标准设计。建议路径：先用周末做一个完整的 RAG 小项目（自己选一个真实文档库），再对着一份真实企业的验收单模板学怎么写指标。约 1-2 个月。

运维/实施工程师：交付是长板，缺的是「代码量」

你已有：客户沟通、现场交付、排障能力——这是 FDE 最值钱的技能，很多人意识不到。要补的是 Python 基础 + 大模型 API 调用 + 一个向量库的实操。不需要刷算法题，能写胶水代码就行。约 2-3 个月。

数据分析：懂业务是长板，缺的是「工程化」

你已有：SQL、业务理解、报表思维。要补的是工程侧：API 调用、Docker 基础、检索链路。你的差异化打法是选「数据密集型行业」（金融、零售）的 FDE 岗位，业务理解就是护城河。

共同的最后一课：真实项目

三条路最后都要落到同一个点上——完整做过一个真实交付。没有交付案例，面试时讲不出细节。这份 FDE 学习路线图把三个方向的每一天要做什么都列成了清单，配套的实训营有可交付的练习项目。
